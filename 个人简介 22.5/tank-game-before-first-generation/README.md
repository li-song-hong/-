# 坦克大战 · LSH 原创地图

一款使用原生 HTML、CSS 和 Canvas 制作的俯视角坦克射击游戏。没有构建步骤，也没有第三方依赖。

本版本针对附加题要求整理：游戏使用“浪尖儿大学社区”图片作为校园底图；中央可摧毁砖墙按照 `LSH` 组成字母布局，同时在游戏画布、主菜单和底部状态栏展示 `LSH` 原创地图签名。

## 运行

直接双击 `index.html` 即可开始。也可以在当前目录启动任意静态文件服务器：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 操作

- 单人：`W/A/S/D` 移动，`空格`、`J` 或鼠标左键开火（可以按住）
- 双人：P1 使用 WASD + 空格；P2 使用方向键 + 小键盘 `0`（也可用 `Enter`）
- `P` 或 `Esc`：暂停 / 继续
- 手机和平板：使用画面两侧的虚拟方向键与 FIRE 键

## 已实现玩法

- 单人战役与双人协作模式；P2 有独立装甲、武器和强化状态
- 三个阶段、递增波次和六类普通敌人（侦察、突击、机枪、重装、无人机、狙击）
- 坦克倒地与队友救援：靠近倒地队友 5 秒即可复活，全部倒地才会失败
- 协同阵型：两台坦克靠近时会建立可见的数据链路，并获得 18% 射速加成
- 泰坦 Boss 三阶段弹幕、扇形攻击和环形攻击
- 可摧毁砖墙、不可摧毁钢墙、基地防守与边界碰撞
- 火力、护盾、治疗、超频四类随机强化
- 三档难度、连击计分、射击冷却、受伤无敌
- 主菜单、暂停、帮助、结算、HUD、音效和移动端操作

## 对照题目要求

- 基础可玩性：支持坦克移动、连续发射炮弹和即时射击反馈。
- 敌人、障碍物和碰撞：有多类敌方坦克、砖墙/钢墙、边界、基地和胜负判定。
- 清晰界面：常驻显示生命、得分、关卡、剩余目标和冷却状态。
- 原创性加分：第一关地图中心的砖墙排列为 `LSH`，画布和界面也有同样的原创地图签名。
- 底图加分：`assets/wavepeak-campus.jpg` 会由 Canvas 按比例铺满，并通过半透明蒙层保证游戏对象清晰。

## 代码从哪里开始看

1. `index.html`：页面结构和全部界面层。
2. `styles.css`：科技风视觉和响应式布局。
3. `game.js`：完整游戏逻辑，已按“配置 → 输入 → 关卡 → 更新 → 绘制 → 主循环”分区。

常用修改入口：

- 全局手感：`game.js` 顶部的 `CONFIG`
- 难度倍率：`DIFFICULTY`
- 敌人属性：`ENEMY_TYPES`
- 波次编排：`LEVELS`
- 地图障碍物：`buildMap()`
- Boss 弹幕：`updateBoss()`、`bossFan()`、`bossRadial()`

如你的姓名缩写不是 `LSH`，请同时修改 `game.js` 顶部的 `AUTHOR_MARK`、`buildLSHSignatureLayout()` 中的砖墙布局，以及 `index.html` 中出现的 `LSH` 文案。

所有角色与特效均由 Canvas 实时绘制，因此可以在没有图片素材的情况下独立运行。

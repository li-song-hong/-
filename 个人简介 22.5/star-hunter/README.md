# 星际猎杀号

一款原生 Canvas 实现的科技风网页飞机大战，无需安装第三方依赖。

## 运行

可直接双击 `index.html` 开始游戏。

也可以启动本地静态服务器：

```bash
npm run dev
```

浏览器访问 `http://localhost:5173`。

## 操作

- 单人模式：鼠标/触控拖动，或 WASD/方向键移动。
- 双人模式：玩家 1 使用 WASD、Shift、空格；玩家 2 使用方向键、`/`、Enter。移动端使用两根手指分别拖动，并可点击两组独立技能按钮。
- 战机会自动射击。
- 空格释放量子炸弹，Shift 相位冲刺，P 暂停。
- 击落敌机收集强化道具，故事模式最终挑战三阶段 Boss。

## 游戏内容

- 四个由简单到地狱难度递增的剧情关卡，以及无尽模式。
- 剧情关卡采用分批增援结构：敌机数量逐批提升，每局至少 3 个首领，高难度会随机增加到 4–6 个。
- 哨兵、突击者、幽灵三种不同属性的可选战机。
- 单人和本地双人合作模式。
- 基于浏览器本地存储的历史排名，保留最高 10 条战绩。
- 首领击破进度条、中文系统语音任务播报与连败鼓励。
- 系统提示使用自定义鼓励台词，并按三个阶段使用不同的中文系统语音音调/语速风格；不播放视频原台词。
- 隐形敌机与稀有道具，包括移速、穿甲、生命核心、资源磁铁、额外炸弹和僚机支援。

## 适配标准

所有新增界面和玩法需要同时支持 PC 与移动端。PC 端提供键鼠操作，移动端提供触控操作；首页、HUD、弹窗和游戏按钮均使用响应式布局。

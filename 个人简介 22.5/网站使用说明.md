# 李松鸿的个人网站

在浏览器中打开 `index.html` 即可查看。小游戏如需完整运行，建议在本目录启动静态服务器：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

再访问 http://127.0.0.1:8765 。使用完在终端按 Ctrl+C 关闭。

- `index.html`：首页结构与固定文案。
- `assets/profile.css`：排版、配色、响应式和打印样式。
- `assets/profile.js`：个人信息、经历、作品数据，以及筛选、播放和复制交互。
- `index-优化前备份.html`：本次修改前的完整首页。
- `index-樱花雪景版.html`：原有的樱花雪景版本。
- `网站优化预览.jpg`：新版桌面首页截图。

本次修改保存在本地，未发布到线上。
